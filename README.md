## 📌 Overview

This repository hosts the source code for my personal portfolio website, engineered to provide a clean, minimalist, and responsive user experience. It highlights my background as a **Software Engineer** specializing in **Python backend systems, Django REST APIs, ERP modernization**, and generative AI implementations.

---

## ✨ Key Features

- ⚡ **Next.js & React App Architecture**: Built with modern static site export optimization for blazing fast load speeds.
- 🎨 **Minimalist Dark Aesthetic**: Deep-space background (`#070B14`) enhanced with ambient radial glows and glassmorphism.
- 📱 **Fully Responsive & Accessible**: Flawlessly adapts across desktop, tablet, and mobile screens.
- 🧩 **Interactive Bento Hub**: Features categorized tabs for **About & Skills**, **Work Experience**, **Featured Projects**, **Education**, and **Contact**.
- 🎬 **Fluid Framer Motion Animations**: Smooth page transitions, micro-interactions, and staggered scroll appearances.
- 🔍 **SEO & Search Optimized**: Pre-configured with OpenGraph cards, `robots.txt`, dynamic `sitemap.xml`, and Google Search Console verification.
- 🚀 **Automated CI/CD**: Seamless GitHub Actions deployment pipeline targeting GitHub Pages.

---

## 🛠️ Tech Stack

### **Frontend & Frameworks**
- **Core**: [Next.js](https://nextjs.org/) (Static Export), [React 18](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/), PostCSS, Custom Glassmorphism
- **Motion & UI**: [Framer Motion](https://www.framer.com/motion/), [Radix UI](https://www.radix-ui.com/), [Lucide React Icons](https://lucide.dev/)

### **Developer Tooling & Deployment**
- **Hosting**: [GitHub Pages](https://pages.github.com/) via GitHub Actions
- **Automation**: GitHub Actions CI/CD (`deploy.yaml`)
- **Formatting**: ESLint, Prettier

## 📂 Project Structure

```text
mayur-portfolio/
├── .github/
│   └── workflows/

├── app/
│   ├── globals.css             # Theme tokens, custom glass utilities, grid pattern

├── package.json                # Project dependencies and script runner
├── tailwind.config.ts          # Custom theme extensions and colors
└── tsconfig.json               # TypeScript compiler rules
```

## 🚀 Getting Started

To run this portfolio locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/Mayur-Satpute/Mayur-Portfolio.git
cd Mayur-Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch local development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for Production
```bash
npm run build
```
